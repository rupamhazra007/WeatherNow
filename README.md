# WeatherNow
A modern animated weather forecast web application with real-time weather updates, location-based forecasting, hourly insights, and a beautiful glassmorphism UI.

**📌 About the Project**
WeatherNow is a responsive weather forecasting application that provides accurate real-time weather information using the Open-Meteo API. The application features a premium animated interface with dark/light mode, hourly forecasts, 7-day predictions, geolocation support, and smooth modern UI effects.

Built for speed, simplicity, and an engaging user experience.

**✨ Features**
🌍 Real-Time Weather Forecast
📍 Geolocation Support
🌡️ Celsius / Fahrenheit Toggle
⏱️ Hourly Weather Updates
📅 7-Day Forecast
🌌 Animated Aurora Background
🌓 Dark & Light Mode
💎 Glassmorphism UI Design
⚡ Fast API Integration
📱 Fully Responsive Design
🎨 Smooth Animations & Transitions

**🛠️ Technologies Used**
PHP
HTML5
CSS3
JavaScript
Open-Meteo API

**🌟 Why WeatherNow?**
WeatherNow combines accurate forecasting with a modern animated interface to create a fast, beautiful, and engaging weather experience.
